# covid19-election-brazil-ols
The Impact of COVID-19 on the 2022 Election Outcome in Brazil (OLS model). Municipal-level analysis in R using TSE, Brasil.IO and IBGE data.
## Dados

Os arquivos de dados não estão neste repositório por causa do tamanho.
Eles podem ser obtidos de duas formas:

**1. Nas fontes originais**

| Dado | Fonte | Observação |
|---|---|---|
| Votação 2º turno (2018 e 2022) | [TSE, Dados Abertos](https://dadosabertos.tse.jus.br/) | Votação nominal por município e zona |
| Casos e óbitos de COVID-19 | [Brasil.IO](https://brasil.io/) | Acumulado de fev/2020 a mar/2022 |
| PIB per capita e urbanização | [IBGE/SIDRA](https://sidra.ibge.gov.br/) | PIB 2020 e Censo 2010 |
